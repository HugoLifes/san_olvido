# San Olvido · *Fuera de Foco*

> **"En San Olvido, lo que nadie mira, muere."**

ARPG souls-like oscuro en estilo 2D-HD (pixel art en un diorama 3D), con vista 3/4 tipo Diablo. La mecánica central es **el foco de la cámara**: solo existe lo que está dentro de la franja enfocada.

## Jugar
Abre `index.html` en Chrome o Edge. Necesitas teclado, mouse e internet (carga three.js desde un CDN).

O sirve la carpeta con un servidor local:
```bash
python -m http.server 8000
```
y entra a http://localhost:8000

## Controles rápidos
WASD + mouse · clic: atacar · clic derecho: flash (parry) · espacio: esquiva · Q/E o rueda: mover la franja de foco · F: foto · H: veladora · R: interactuar · I: personaje
